# 법률 검토: 처리 완료된 신청 건의 제출 서류 노출 여부

- 작성일: 2026-11-19
- 대상 화면: 기안자 "내 신청함"
- 성격: 검색으로 확인한 조문 요약이며 법률 자문이 아닙니다. 실제 적용 전에 담당 법무 부서의 확인이 필요합니다.

## 1. 검토 질문
신청이 완료(승인 또는 반려)된 건에 대해, 기안자의 신청함 화면에 제출한 서류를 계속 보여줘야 하는가?

## 2. 결론
- 처리가 끝난 건의 제출 서류를 화면에 상시 노출하지 않아도 법적으로 문제될 가능성은 낮다.
- 다만 본인이 요구하면 열람할 수 있는 경로는 있어야 한다. (개인정보 보호법 제35조)
- 프로토타입 적용: 신청이 진행 중일 때만 제출 서류를 표시하고, 완료·반려 후에는 숨긴 뒤 "서류 열람 요청" 버튼을 제공한다.

## 3. 근거
### 3.1 개인정보 보호법 제35조 (개인정보의 열람)
- 정보주체는 개인정보처리자가 처리하는 자신의 개인정보에 대한 열람을 해당 개인정보처리자에게 요구할 수 있다.
- 제출 서류에는 본인 정보가 들어 있으므로 열람 요구 대상이 된다.
- 이 조항은 요구가 있을 때 응해야 한다는 것이지, 화면에 상시 노출하라는 뜻은 아니다.
- 열람을 제한하거나 거절할 수 있는 사유가 있다. 법률에 따라 열람이 금지되거나 제한되는 경우, 제3자의 재산이나 이익을 부당하게 침해할 우려가 있는 경우 등이다.
- 거절하거나 연기하려면 사유와 이의제기 방법을 요구를 받은 날부터 10일 이내에 알려야 한다.

### 3.2 행정절차법 제37조 (문서의 열람 및 비밀유지)
- 당사자의 처분 관련 문서 열람·복사 요청은 의견제출 기한까지 또는 청문이 끝날 때까지로 시기가 한정되어 있다.
- 따라서 처리가 끝난 건에 상시 열람을 보장하는 근거로는 맞지 않는다.
- 출처: https://korea.legal/wiki/%ed%96%89%ec%a0%95%ec%a0%88%ec%b0%a8%eb%b2%95-%ec%a0%9c37%ec%a1%b0/

### 3.3 실제 사례: 복지로 개인정보처리방침
- 복지로(보건복지부·한국사회보장정보원)는 서비스 신청 정보 중 신청 상세정보를 결과 통보일부터 90일, 신청 이력(신청 결과 내역)을 5년 보유한다고 공개하고 있다.
- 완료 후에는 상세 서류를 계속 보이게 하지 않는 것이 실무와 가깝다는 참고 사례다.
- 출처: https://www.bokjiro.go.kr/ssis-tbu/cms/pc/customer/site/01/history/1306081_1311.html

## 4. 프로토타입 적용 내용
| 상태 | 제출 서류 표시 | 비고 |
|---|---|---|
| 접수, 체크완료, 심사중 | 표시 | 진행 중에는 제출 내용 확인 가능 |
| 완료, 반려 | 숨김 | 안내 문구와 "서류 열람 요청" 버튼 표시 |

- 열람 요청은 DB(`wf_view_log`)에 기록된다. 담당자가 확인하고 처리하는 화면은 아직 없다.
- 장기요양·장애 대리신청 건은 부모의 장애진단서 같은 민감 정보가 포함되어, 대리인에게 계속 보이는 것을 특히 주의해야 한다. (조문 확인 사항이 아니라 위험 판단이다.)

## 5. 확인하지 못한 사항
- 사회보장급여법 등 개별 법령에 신청 서류 열람이나 처리결과 통지를 직접 정한 조항이 있는지 확인하지 못했다.
- 실제 사업의 보유기간, 열람 범위, 대리인 열람 가능 여부는 해당 법령과 기관 지침을 별도로 검토해야 한다.
- 프로토타입의 부서 구분은 화면 수준이며, 실제 접근 통제는 별도 설계가 필요하다.
