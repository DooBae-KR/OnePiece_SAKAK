# 복지행정 오류·사각지대 점검 프로토타입

사회보장 데이터·AI 활용 공공성 아이디어 공모용 프로토타입 (전자결재형 웹페이지).

- `index.html` : 단일 파일 웹페이지. 브라우저에서 열면 Supabase REST로 데이터를 읽고 씁니다.
- `schema.sql` : `wf_` 테이블 5개와 RLS 정책(시연용으로 anon 개방).
- `seed.sql` : 합성 시연 데이터 (절차 3, 서류 19, 신청 15, 카드별 서류 65).

## 주의
- 모든 데이터는 합성 데이터입니다. 실제 개인정보를 넣지 마세요.
- `wf_` 테이블은 시연용으로 누구나 읽고 쓸 수 있게 열려 있고, 부서 구분은 화면 수준입니다.
- 외부 클라우드(Supabase)는 행정망에서 쓸 수 없습니다. 실제 적용 시 내부 DB로 이전해야 합니다.
- 서류 열람 보호는 화면 수준(다운로드·복사 차단, 워터마크)이며 화면 캡처는 막지 못합니다.
